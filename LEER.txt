Dependencias utilizadas:

- express: Framework para crear la API REST.
- cors: Habilita peticiones desde otros orígenes.
- dotenv: Carga variables de entorno desde el archivo .env.
- express-validator: Validación de datos recibidos.
- jsonwebtoken: Generación y validación de tokens JWT.
- morgan: Registro de peticiones HTTP.
- multer: Carga de archivos e imágenes.
- mysql2: Conexión con la base de datos MySQL.
- pdfkit: Generación de reportes PDF.
- swagger-jsdoc: Generación de documentación OpenAPI.
- swagger-ui-express: Visualización de la documentación Swagger.
